# Similis

Photo gallery with content-based image retrieval and FRE relevance feedback. Source code: https://github.com/Taki-eddine-El-Attari/Similis

Open the app at its direct address, https://said30-similis.hf.space. Inside the Hugging Face page the app runs in an iframe, and the browser does not send the session cookie there, so sign-in fails.

This Space has no persistent storage: accounts and uploaded photos are erased when the Space restarts or wakes up from sleep.
